## Add a new salon

1. Copy the `dear-beauty` folder and rename it with the salon's short name, e.g. `salong-lumi`.
2. In the new `index.html`, change: the logo, the colors at the top of the style section, the welcome text, and `REVIEW_LINK` (the salon's Google review link).
3. Commit and push. The page is live at https://reviews.aiscent.co/salong-lumi/ within a minute or two.
4. Test on a phone, then program the salon's NFC stickers with that address.

## Rules

- This repository is public. Only public information goes here: salon names, logos, public Google review links.
- Never put passwords, API keys, customer data or private notes in this repository.
- Keep `CNAME` as it is, or the custom domain stops working.
